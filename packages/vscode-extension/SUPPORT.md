# NotebookFlow support

For bugs and feature requests, open a
[GitHub issue](https://github.com/NoelHuibers/notebookflow/issues). Include the
Visual Studio Code version, extension version, operating system, and relevant
lines from the **NotebookFlow Engine** output channel. Remove notebook data,
API keys, tokens, and other secrets before posting logs.

Security reports should follow the private reporting instructions in the
repository's [Security policy](https://github.com/NoelHuibers/notebookflow/security/policy).
